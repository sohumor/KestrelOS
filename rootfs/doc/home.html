KestrelOS

This page is being rendered by this operating system's own browser: its own HTML parser and layout engine, drawn through its own window manager, over its own TCP/IP stack. Nothing here was ported from anywhere.

The live web

These need working networking. In QEMU that means a NIC on the command line; in VirtualBox, an Intel PRO/1000 adapter.

  • example.com over verified HTTPS
  • neverssl.com over plain HTTP

TLS 1.3 is enabled with certificate verification required. HTTPS, redirects, cookies, caching, chunked bodies and gzip decoding all run through KestrelOS's own libraries.

Linked and imported stylesheets, PNG/JPEG/GIF/BMP images, classic JavaScript, bounded static modules, Promise jobs and asynchronous fetch, live DOM mutation, cookies, form controls and GET/POST submission are enabled. Script changes are re-styled and re-laid out. Small i32 WebAssembly modules, single-line flex rows and basic inline SVG shapes are also supported.

The limits are real: let/const currently have var semantics and module bindings are not live. import.meta.url works, and literal-string import() returns a Promise, but those modules are eagerly loaded and computed imports are unsupported. Inline modules report the document URL; external modules require a JavaScript MIME type and obey fetch-style CORS/cookie rules. Inline SVG has polygons, polylines and a bounded, single-subpath command subset, not complete paths, arcs or effects. Its default viewBox scaling is centered and aspect-preserving, one missing dimension can be derived from that ratio, and coordinate/raster work is capped. Downloadable webfonts, media codecs and playback are not implemented; video can show a poster and audio/video otherwise use fallback boxes. HTTPS uses HTTP/1.1 over TLS 1.3 — HTTP/2 and HTTP/3 are not implemented. The from-scratch cryptography has not had a professional audit. Complex sites will still degrade or fail; this browser does not claim compatibility with every website.

Getting around

  • Click a link to follow it
  • Back, Fwd and Reload, or ctrl-B / ctrl-F / ctrl-R
  • ctrl-L types in the address bar, enter goes
  • Arrows and PgUp/PgDn scroll, ctrl-Q quits

Run browser -t <url> from a shell to render any page as plain text instead — that works over a serial console with no graphics at all.
