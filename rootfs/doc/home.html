KestrelOS

This page is being rendered by this operating system's own browser: its own HTML parser and layout engine, drawn through its own window manager, over its own TCP/IP stack. Nothing here was ported from anywhere.

Local pages

  • welcome.md — a guided tour of the shell
  • test.html — what the HTML engine supports
  • /etc/motd — the login banner
  • /etc/version — the release string

The live web

These need working networking. In QEMU that means a NIC on the command line; in VirtualBox, an Intel PRO/1000 adapter.

  • example.com
  • neverssl.com

There is no TLS, so https:// addresses are refused rather than half-supported. Most of the modern web is therefore out of reach; plain-HTTP pages work.

Getting around

  • Click a link to follow it
  • Back, Fwd and Reload, or ctrl-B / ctrl-F / ctrl-R
  • ctrl-L types in the address bar, enter goes
  • Arrows and PgUp/PgDn scroll, ctrl-Q quits

Run browser -t <url> from a shell to render any page as plain text instead — that works over a serial console with no graphics at all.
